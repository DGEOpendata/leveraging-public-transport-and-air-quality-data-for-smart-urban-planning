# Leveraging Public Transport and Air Quality Data for Smart Urban Planning

This project aims to combine public transport usage data and air quality indices to inform smart urban planning strategies in Abu Dhabi. By integrating these datasets, we can provide insights for improving public transport efficiency and reducing environmental impact.

## Requirements

- Python 3.8+
- Pandas library
- Matplotlib library

## Installation

1. Clone the repository:
   bash
   git clone https://github.com/example/smart-urban-planning.git
   cd smart-urban-planning
   

2. Install the required packages:
   bash
   pip install pandas matplotlib
   

## Usage

1. Ensure you have the datasets:
   - `Public_Transport_Usage_Statistics.csv`
   - `Air_Quality_Index_by_Location.json`

2. Run the analysis script:
   bash
   python analyze_transport_air_quality.py
   

3. The script will output the peak hours for public transport usage and the average air quality index during these times. It will also provide suggestions for environmental improvements if necessary.

4. A graphical plot will be displayed showing public transport ridership by hour.
